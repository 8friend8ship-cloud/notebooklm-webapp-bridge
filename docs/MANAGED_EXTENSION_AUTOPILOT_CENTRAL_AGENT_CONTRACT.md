# Central Agent contract

For every app/platform workflow, Central Agent checks whether an existing Chrome extension can satisfy the requirement before creating a new one. If a new extension or version is justified, Central Agent owns source creation, static QA, package staging, dedicated-Chrome loading, runtime verification, success/failure history, LAST_GOOD and rollback. The user is not asked to download/extract/reload managed packages manually. The final routine manual gate is ChatGPT Computer Use exact-site permission confirmation; higher-impact approval boundaries remain explicit.
