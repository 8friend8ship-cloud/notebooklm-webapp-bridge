# User gate for managed Chrome extensions

After Central Agent completes source sync, package validation, automatic staging, dedicated-Chrome load, extension ID/version readback, and same-fixture x2 runtime QA, the normal user action is only:

`ChatGPT -> Computer Use -> Google Chrome -> Site permissions` and confirm the exact allowlisted domains requested by Central Agent.

Additional explicit user approval is still required for new OAuth, new scopes, new secrets, paid API/credits, public publish, destructive changes, or payment/contract actions.
